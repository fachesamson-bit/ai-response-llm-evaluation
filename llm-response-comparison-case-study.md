# LLM Response Comparison — Case Study

> **Portfolio Demonstration — Synthetic Example**
>
> This fictional case study demonstrates comparative evaluation of two AI-generated responses. It does not contain confidential client, platform, benchmark, or proprietary task data.

## Scenario

Two AI systems are given the same user prompt.

The evaluator must determine which response provides the better answer based on factuality, relevance, completeness, clarity, and instruction following.

---

# User Prompt

> "Explain why airplanes can fly. Give me a simple explanation in three bullet points."

---

# Response A

> * An airplane flies because its wings generate lift as air moves around them.
> * The engines provide thrust, which moves the airplane forward through the air.
> * The wings and airplane's forward motion allow the aircraft to produce enough lift to support its weight.

---

# Response B

> * Airplanes fly because their engines push them upward into the sky.
> * The wings create lift, but the engine is the main reason an airplane stays in the air.
> * Larger airplanes need more powerful engines because they are heavier.

---

# Comparative Evaluation

## 1. Instruction Following

### Response A

**Assessment:** Strong

The response follows the requested format:

* Exactly three bullet points
* Simple explanatory language
* Directly addresses why airplanes can fly

### Response B

**Assessment:** Strong

Response B also provides exactly three bullet points and uses relatively simple language.

**Result:** Tie

Both responses satisfy the explicit formatting requirement.

---

# 2. Factuality

### Response A

**Assessment:** Strong

The response correctly distinguishes between:

* Lift
* Thrust
* Weight

It explains that forward motion and the aerodynamic characteristics of the wings enable the aircraft to generate lift.

### Response B

**Assessment:** Weak

The first bullet incorrectly states that the engines push the airplane upward into the sky.

Aircraft engines primarily provide **thrust**, while the aerodynamic forces generated by the wings provide **lift**.

The second bullet also incorrectly implies that the engine is the main reason an airplane stays in the air.

**Result:** Response A is substantially better.

---

# 3. Relevance

### Response A

**Assessment:** Strong

Every bullet contributes directly to explaining flight.

### Response B

**Assessment:** Moderate

The response discusses engines, wings, and aircraft weight, so it remains related to the question. However, some of its explanation is based on an inaccurate description of the forces involved.

**Result:** Response A is better.

---

# 4. Completeness

### Response A

**Assessment:** Strong

The response identifies the important concepts necessary for a basic explanation:

* Lift
* Thrust
* Weight
* Forward motion

For a simple three-point explanation, this provides sufficient coverage.

### Response B

**Assessment:** Moderate

Response B mentions wings, engines, and weight but does not accurately explain the relationship between the forces.

**Result:** Response A is better.

---

# 5. Clarity

### Response A

**Assessment:** Strong

The wording is straightforward and accessible to a general audience.

### Response B

**Assessment:** Strong in presentation, weak in accuracy

The wording is easy to understand, but its simple explanation communicates an incorrect physical relationship.

**Result:** Response A is better overall.

---

# Comparative Scorecard

| Dimension             | Response A | Response B    |
| --------------------- | ---------- | ------------- |
| Instruction Following | Strong     | Strong        |
| Factuality            | Strong     | Weak          |
| Relevance             | Strong     | Moderate      |
| Completeness          | Strong     | Moderate      |
| Clarity               | Strong     | Strong        |
| Overall Quality       | Strong     | Weak–Moderate |

---

# Final Decision

## Response A is the better response.

**Reason:**

Response A provides a simple three-point explanation while correctly distinguishing the major aerodynamic forces involved in flight.

Response B follows the requested format and uses clear language, but it contains a fundamental factual error by attributing upward motion primarily to the engines.

This illustrates an important evaluation principle:

**A response that is clear and well-formatted is not necessarily a high-quality response if its central explanation is factually incorrect.**

---

# Severity Assessment

### Response A

**Major:** None identified
**Moderate:** None identified
**Minor:** None identified

### Response B

**Major:** Incorrect explanation of the role of engine thrust in producing upward lift.

**Impact:** The error affects the central concept being explained and could leave the user with a fundamentally incorrect understanding of why aircraft fly.

---

# Why Response A Wins

The comparison should not be based on which response sounds more confident or polished.

Instead, the evaluator should prioritize:

1. Correctness
2. Compliance with the user's requirements
3. Relevance
4. Completeness
5. Clarity

In this example, both responses perform well on formatting and general relevance, but Response A performs substantially better on factual accuracy.

---

# Comparative Evaluation Workflow

A practical A/B evaluation can follow this sequence:

**Understand Prompt → Evaluate A → Evaluate B → Compare → Identify Critical Differences → Select Better Response → Document Rationale**

### Understand Prompt

Identify the user's objective and explicit constraints.

### Evaluate A

Assess Response A independently before comparing it with Response B.

### Evaluate B

Apply the same criteria to Response B.

### Compare

Identify meaningful differences rather than simply counting the number of issues.

### Identify Critical Differences

Determine whether any error substantially affects the answer.

### Select Better Response

Choose the response that better satisfies the user's requirements.

### Document Rationale

Explain the decision using specific, evidence-based observations.

---

# Important Comparative Evaluation Principle

**The better response is not necessarily the longer response.**

A high-quality response should provide the information required to satisfy the user's objective while maintaining accuracy and clarity.

Similarly, one small error should not automatically make a response worse if the error has little impact. Evaluators should consider the **severity and significance** of issues rather than simply counting them.

---

# Quality-Control Checklist

Before making an A/B evaluation:

* [ ] Understand the user's objective.
* [ ] Identify explicit formatting or content requirements.
* [ ] Evaluate each response independently.
* [ ] Check factual claims.
* [ ] Check relevance.
* [ ] Check completeness.
* [ ] Check instruction following.
* [ ] Check clarity.
* [ ] Identify meaningful differences.
* [ ] Consider the severity of errors.
* [ ] Select the stronger response.
* [ ] Provide a concise evidence-based rationale.
